# Nanexus V0.1 — Implementation Summary

Verified V0.1 behavior for operators and integrators. See also the README and [v0.1-architecture-overview.md](v0.1-architecture-overview.md).

## Verified baseline

| Component | Verified in V0.1 |
|-----------|------------------|
| Python | 3.12 (`>=3.12,<3.13`) |
| Frigate | Authenticated API on port **8971**, Frigate **0.17.1** |
| Planning model | Local Ollama `qwen3:14b` |
| Vision model | Local Ollama `moondream:1.8b` (optional) |
| Persistence | SQLite domain DB + local retained-media store under `.local/` |

## Frigate compatibility vs upstream security

- **Verified compatibility:** Nanexus V0.1 was tested against authenticated Frigate **0.17.1**. That is a historical test baseline, not a recommendation to run an unpatched upstream forever.
- **Upstream maintenance:** For new deployments, follow Frigate’s current security-maintained releases and your organization’s patch policy. Nanexus does **not** claim compatibility with Frigate versions that have not been verified in this project.
- Access uses supported authenticated APIs (not the unauthenticated internal port). Nanexus does not modify Frigate configuration, recordings, or runtime.

## Configuration loading

| Settings | How they are applied |
|----------|----------------------|
| `NANEXUS_FRIGATE_*` | Private file pointed to by `NANEXUS_FRIGATE_ENV` (default `.local/frigate.env`) |
| Web / Ollama / models / TZ | Process environment (`WebConfig.from_env`) |

Copying `.env.example` to `.local/frigate.env` does **not** by itself export Web/Ollama settings.

## Web Console

- Default bind: `127.0.0.1:8787` (localhost-only).
- Health: `ok` is process liveness; `frigate.ready` / `ollama_*` report dependency readiness. Missing Frigate configuration yields `frigate.ready: false`, not an HTTP 500.
- One investigation at a time; reopen restores form + results from durable artifacts without re-running the Agent.

## Known V0.1 limitations

- Selective snapshot retrieval; ordinary searches may not retain media.
- VLM text is qualified model opinion.
- Conservative anti-repeat may leave a Case `partial` after useful evidence was obtained.
- No production multi-user authentication; LAN bind is optional and allowlist-based only.
- Frigate-first only in this milestone; other VMS adapters are not shipped.
